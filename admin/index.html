완료 운행 관리

관리자 계정으로 로그인한 뒤 운행 기록을 관리하세요. 공개 후기에는 운행일·출발 시간·출발지·도착지·금액만 표시됩니다.

개인정보 보호: 고객 이름, 전화번호, 주민등록번호, 차량번호 등은 입력하지 마세요. 아래 폼은 승인된 5개 항목과 운행 상태만 받습니다.
설정이 필요합니다.

Supabase 프로젝트 URL과 공개 anon/publishable 키를 저장소 루트의 supabase-public-config.js에 설정한 뒤 새로고침하세요. 비밀 service_role 키는 절대 입력하지 마세요.

관리자 로그인

관리자 비밀번호 재설정

새 비밀번호를 두 번 입력해 주세요. 설정이 완료되면 새 비밀번호로 로그인할 수 있습니다.

인증된 계정만 데이터베이스 정책에 따라 관리할 수 있습니다.

운행 기록 등록

서비스 구분은 반드시 선택하세요. 엑셀 첫 열도 서비스구분(탁송/대리운전)으로 준비합니다. 완료 상태인 기록만 공개 후기 목록에 표시됩니다.

엑셀/CSV 일괄 업로드

CSV UTF-8 파일을 선택하세요. 첫 행은 열 제목이며 열 순서는 서비스구분, 운행일, 출발시간, 출발지, 도착지, 금액입니다. 개인정보는 넣지 마세요.

관리자 비밀번호 변경

로그인한 관리자만 현재 비밀번호를 변경할 수 있습니다. 새 비밀번호는 8자 이상으로 입력하세요.

경로별 참고요금 검토·승인

완료 운행만 서비스별·출발지·도착지별로 묶어 후보 금액(중앙값)을 계산합니다. 후보는 자동 승인되지 않습니다. 운영자가 각 경로의 금액을 직접 승인한 뒤 JSON을 내려받아 data/reference_fares.json에 반영해야 홈페이지 요금계산기에 표시됩니다.
