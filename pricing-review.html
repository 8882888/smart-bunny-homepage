완료 운행 기록 요금 검토 도구

완료 운행 기록을 브라우저 안에서 분석해 반복 경로의 금액 분포를 검토합니다. 이 도구는 요금을 자동 승인하거나 홈페이지 요율을 변경하지 않습니다.

개인정보 보호 안내
파일은 브라우저 안에서만 처리되며 서버로 업로드하지 않습니다. 원본 파일에 이름, 전화번호, 주민등록번호, 차량번호 등 불필요한 개인정보가 있으면 먼저 제거하세요. 결과 내보내기에는 출발지·도착지별 개별 기록이 아니라 집계 정보만 포함합니다.

1. 완료 운행 파일 선택

프로젝트의 data/completed_trips.json 또는 같은 구조의 JSON 파일을 선택하세요.

파일을 선택하면 브라우저에서 분석합니다.

2. 분석 결과

현재 기록에는 서비스 종류(대리운전/탁송), 차종, 주행거리, 시간대별 요금 구분이 없으므로 아래 결과는 참고용 집계이며 확정 요율 산정에 바로 사용할 수 없습니다.
